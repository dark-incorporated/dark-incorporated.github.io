# Contributing

How issues, pull requests and docs work across the coven is in the org's [`CONTRIBUTING.md`](https://github.com/bevy-coven/.github/blob/main/CONTRIBUTING.md), and every README and docs page follows the one documentation guide, [`DOCUMENTATION.md`](https://github.com/bevy-coven/.github/blob/main/DOCUMENTATION.md). A change that a user can see updates its crate's README, its `docs/` folder and its page in this book in the same pull request.
